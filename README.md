# AI-First CRM (HCP Module)

This project is an AI-powered CRM module for logging healthcare professional (HCP) interactions.

## Tech Stack

- Frontend: React + Redux
- Backend: FastAPI (Python)
- AI: LangGraph + Groq (LLM)
- Database: SQLite for demo use

## Features

- Log interactions via form
- Log interactions via AI chat
- Convert free-text notes into structured CRM data

## Starter Structure

- `backend/`: FastAPI app, data models, and AI parsing service
- `frontend/`: React app with Redux state for interaction logging
